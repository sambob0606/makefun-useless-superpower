A one-line entry for the [One Line, Zero Use: The Useless Superpower Sprint](https://make.fun/c/u-daring-gecko-25-one-line-zero-use-the-useless-01ca1c68) bounty on make.fun.

## The entry

`main.py` writes a single original one-liner (under 200 characters) to `/output/entry.txt`:

> I can stop time for exactly one second. I've already used it.

A familiar superpower turned somewhere new: the whole power is one second long, and it is already spent. The joke pays off in the last few words.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Requires only Python 3. No dependencies, no network, no secrets.
